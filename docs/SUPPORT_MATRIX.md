## Database guarantees

### PostgreSQL

PostgreSQL is the default for production multi-user and multi-node deployments. Production support still requires migration, backup/restore, tenant isolation, concurrency and upgrade tests.

### SQLite

SQLite is intended for embedded and single-host deployments. The SQLx connection adapter enables foreign keys, WAL journaling and a bounded busy timeout. Do not share a WAL database over a network filesystem or across application hosts. SQLite is not represented as equivalent to PostgreSQL for multi-node high-write workloads.

## Update policy

- Update versions in one reviewed dependency/toolchain change.
- Review upstream release notes and compatibility requirements.
- Run all Rust, web, database and migration checks after an update.
- Keep lockfiles committed once generated by the supported toolchains.
